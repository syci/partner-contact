To use this module, you need to:

1. Go to the partner/contact form.
2. Open the **Social Media** tab.
3. Fill in any of the available profile URL fields:

   - LinkedIn Profile URL
   - Twitter/X Profile URL
   - GitHub Profile URL
   - Facebook Profile URL
   - Instagram Profile URL
   - YouTube Channel URL

4. Saved URLs are displayed as clickable links that open the profile directly
   in a new browser tab.
